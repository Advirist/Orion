# Fortnite

## Overview
Fortnite is a popular multiplayer video game developed by Epic Games. It combines building, battle royale, and action elements in a vast, procedurally generated world.

## Game Modes
- **Battle Royale**: Up to 100 players compete to be the last person or team standing.
- **Creative Mode**: A sandbox mode where players can build structures and create custom maps.
- **Save the World**: A cooperative mode against waves of zombies.

## Features
- **Free-to-play**: Most content is free, with microtransactions for cosmetic items.
- **Cross-platform Play**: Supports multiple platforms including PC, Xbox, PlayStation, and mobile devices.
- **Regular Updates**: Continuously updated with new maps, challenges, and seasonal events.
